# Vendored viewer assets

- `online3dviewer/o3dv.min.js`: Online 3D Viewer 0.18.0, MIT license.
- `occt/`: `occt-import-js` 0.0.22 and Open CASCADE license notices.

The Online 3D Viewer bundle's OCCT base URL is set to `/static/o3dv/occt/`
so STEP, STP, IGES, and BREP parsing works from this local server.
The upstream engine and source are available at https://github.com/kovacsv/Online3DViewer
and https://github.com/kovacsv/occt-import-js.
